# 五档电量配色追加需求

日期：2026-10-27。与 `ui-titlebar-icon-plan.md` 同属当前 UI worker，避免并行修改同一文件。

## 统一规则

- 0–10：红
- 11–20：橙
- 21–50：黄/赭黄
- 51–80：黄绿/橄榄绿
- 81–100：绿
- 保留 10%/20% 低电提醒阈值；本需求只改颜色，不改通知逻辑。

## 实现要求

1. 在合适的 UI/theme 模块建立唯一 `battery_tier`/色板映射，不在卡片、图标、托盘分别写阈值。五种颜色必须实际不同，并在浅色/深色卡片上可辨；必要时使用语义色的明暗变体，但档级不变。
2. 设备卡片已填充电量格和动态托盘图标使用同一档色；空格仍用 muted。充电不再一律绿色，保留档色并由文字/充电符号表达充电。静态 exe/window/titlebar 品牌图标保持固定色。
3. 百分比文字仍以可读性为主，不能为了显示黄色而降低对比度；颜色不是唯一信息，百分比继续显示。
4. Coarse/Unknown/Asleep/Stale 不伪造百分比档级；粗粒度保持低/中/满语义，未知/过期用 muted。
5. 单元测试覆盖边界 0、10、11、20、21、50、51、80、81、100，验证五档颜色互不相同、>100 不错误归档；卡片与托盘调用同一 helper。
6. 更新 `docs/ui-mockup-pixel.svg/.png` 中示例卡片颜色，避免示意图仍使用旧规则。真实设备截图预计可覆盖 Zero 46、M618 80、OPPO 90 三档；低两档由边界测试验证，不注入假设备。
7. 后续文档任务会在 README/DESIGN 写清五档范围；本 worker 不改这两份文档。

验证纳入当前 UI 任务的构建、测试、截图和交互验收，不能只做颜色常量而不检查实际渲染。
