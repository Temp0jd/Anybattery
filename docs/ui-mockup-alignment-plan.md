# 按 GitHub 示意图对齐 UI（2026-10-27）

来源：`docs/ui-mockup-pixel.svg` / `.png`。只修视觉和布局，不改协议、不改产品行为。

## 已确认的偏差

1. 标题“电池”当前 22px，示意图 28px。改为 28px，保留 `fit_text` 防窄窗溢出。
2. 设备卡片左侧图标块当前是淡色底 + accent 图标；示意图是 32×32 实色 accent 块 + on_accent 图标。改为实色填充、2px 硬边框、图标使用 `p.on_accent`。
3. 低电量横幅当前是淡橙色底 + 橙色文字；示意图是黄色底、深色粗体文字、红色 12×12 方标。按示意图调整，深浅主题保持可读。
4. 页脚当前两行（间隔/刷新时间），示意图是一行“每 60 秒 / 刚刚刷新”，右侧诊断按钮 74×28。改为单行、垂直居中，按钮 74×28。
5. 设备列表固定占满剩余高度，设备少时把页脚推到窗口底部，卡片和页脚之间出现大块空白；示意图中页脚紧跟卡片列表。让 vertical ScrollArea 在内容较少时收缩，footer 紧跟最后一张卡；设备多时仍限高滚动。
6. 内容左右边距当前 20px，示意图相对窗口约 13px；改为 16px，使卡片比例更接近示意图。标题栏内部布局不因此改变。

## 验收

- `cargo xwin build -p anybattery-app --target x86_64-pc-windows-msvc --release`。
- 用现有 `C:\\AnyBattery-test` 截图流程捕获 430×680 与 380×520、150% DPI 的默认页，必须实际看图对照示意图。
- 关键检查：标题尺寸、实色图标块、告警条（可临时用现有低电量设备或代码条件触发，不能伪造设备数据）、单行页脚、诊断按钮宽度、卡片与页脚间距、无文字截断/重叠。
